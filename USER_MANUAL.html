SMHMS 软件使用说明书

一、软件概述

SMHMS（Server Simulation Heating Monitoring System）是一款专业的服务器模拟加热监控系统，通过 Modbus-TCP 协议与加热设备进行通信，实现对加热片各项参数的实时监控与控制。

1.1 主要功能

  • 多站点管理：支持同时管理多个加热站点
  • 实时数据监控：监测加热片的温度、电压、电流、功率等关键参数
  • 加热片控制：远程启动/停止加热片
  • 校准功能：对加热片进行精确校准
  • 报警保护：设置过压、过流、过温阈值，保障设备安全
  • 数据记录：自动记录温度数据并支持 CSV 导出
  • 日志系统：完整的操作日志记录与导出功能
  • 通讯重试：Modbus-TCP 通讯失败时自动重试（默认重试3次，间隔500ms）
  • 多语言支持：支持中文、英文、韩文三种语言
  • 主题切换：支持浅色、深色及跟随系统三种显示模式

1.2 系统要求

本软件支持 Windows 桌面版 和 Android 移动版 两种平台。

Windows 桌面版

  • Windows 10/11 操作系统
  • 显示器分辨率：建议 1920x1080 或更高

Android 移动版

  • Android 5.0 (API 21) 或更高版本
  • 屏幕尺寸：建议 5.0 英寸及以上
  • 支持 Modbus-TCP 网络通信（需要设备连接到与加热设备同一网络）
  • 存储空间：建议预留 100MB 以上可用空间
  • 网络权限：需要网络访问权限以连接加热设备

三、操作指南

3.1 添加站点

  1. 点击主界面右上角的 "+" 按钮

  2. 在弹出的对话框中填写站点信息：

    • 站点名称：自定义名称（必填）
    • IP地址：加热设备 IP 地址（必填）
    • 端口号：Modbus-TCP 端口，默认为 502（必填）
    • 加热片数量：1-6 个（必填）

  3. 点击 "保存" 完成添加

3.2 连接站点

  1. 在站点卡片上点击 "连接" 按钮

  2. 系统尝试建立 Modbus-TCP 连接

  3. 连接成功后，状态指示灯变为绿色

  4. 系统自动开始定时轮询（默认间隔 1 秒）

3.3 断开连接

  1. 在站点卡片上点击 "断开" 按钮

  2. 系统关闭 TCP 连接并停止轮询

3.4 编辑站点

  1. 点击站点卡片上的 "编辑" 按钮

  2. 修改站点信息

  3. 点击 "保存" 确认修改

3.5 删除站点

  1. 点击站点卡片上的 "删除" 按钮
  2. 在确认对话框中点击 "删除"
  3. 站点将从系统中移除

3.6 启动加热片

方式一：站点详情界面

  1. 进入站点详情页面
  2. 找到目标加热片卡片
  3. 点击 "启动" 按钮

方式二：主界面卡片

  1. 在主界面点击站点卡片进入详情
  2. 找到目标加热片
  3. 点击 "启动" 按钮

3.7 停止加热片

  1. 在加热片卡片上点击 "停止" 按钮
  2. 加热片将立即停止工作

3.8 校准加热片

  1. 在站点详情界面点击加热片卡片的 "校准" 按钮

  2. 在弹出的对话框中设置校准占空比（10%-100%）

  3. 点击 "开始校准"

  4. 等待校准完成（最多 30 秒）

  5. 校准成功后会自动读取并显示校准结果

注意：

  • 校准过程中请确保加热片正常工作
  • 校准完成后控制寄存器会自动重置为 0

3.9 设置报警阈值

  1. 进入 "设置" 界面

  2. 选择目标站点和加热片编号

  3. 点击要修改的阈值项：

    • 过压阈值：设置电压保护上限
    • 过流阈值：设置电流保护上限
    • 过温阈值：设置温度保护上限

  4. 输入新的阈值数值

  5. 点击 "保存"

3.10 设置目标功率

  1. 在设置界面选择目标站点和加热片

  2. 点击 "设置目标功率"

  3. 输入目标功率值（W）

  4. 点击 "保存"

3.11 设置最大功率限制

  1. 在设置界面选择目标站点和加热片

  2. 点击 "设置最大功率"

  3. 输入最大功率限制值（W）

  4. 点击 "保存"

    一般校准完成后自动计算最大功率，不需要手动设置

3.12 保存参数到设备

  1. 在设置界面点击 "保存到Flash"

  2. 在确认对话框中点击 "确认"

  3. 系统将参数写入设备持久存储

3.13 导出/导入参数

导出参数：

  1. 进入 "设置" 界面

  2. 点击 "导出参数"

  3. 参数将保存至 smhms_parameters.json 文件

导入参数：

  1. 进入 "设置" 界面

  2. 点击 "导入参数"

  3. 在确认对话框中点击 "确认"

  4. 系统从 smhms_parameters.json 读取并应用参数

3.14 查看温度曲线

  1. 进入站点详情界面

  2. 点击右上角的 "图表" 按钮

  3. 在下拉框中选择加热片编号

  4. 查看该加热片的温度变化曲线

3.15 导出温度数据

  1. 进入站点详情界面

  2. 点击右上角的 "导出" 按钮

  3. 数据将保存为 CSV 格式文件

3.16 查看日志

  1. 点击主界面右上角的 "日志" 图标

  2. 进入日志查看界面

  3. 可执行以下操作：

    • 刷新：重新加载日志
    • 导出：将日志保存为文件
    • 清空：删除所有日志记录

3.17 切换主题

  1. 进入 "设置" 界面

  2. 点击 "主题"

  3. 选择显示模式：

    • 浅色模式：白色背景
    • 深色模式：黑色背景
    • 跟随系统：自动匹配系统设置

3.18 切换语言

  1. 进入 "设置" 界面

  2. 点击 "语言"

  3. 选择语言：

    • 🇨🇳 中文
    • 🇺🇸 English
    • 🇰🇷 한국어

四、Modbus-TCP 通讯说明

4.1 通讯参数

参数 默认值
端口号 502
超时时间 5 秒（连接）/ 10 秒（读取）/ 3 秒（写入）
轮询间隔 1 秒

4.2 重试机制

系统内置智能重试机制：

  • 最大重试次数：3 次
  • 重试间隔：500 毫秒
  • 应用场景：寄存器读取、寄存器写入
  • 触发条件：通讯超时、连接错误

当通讯失败时：

  1. 系统记录错误日志
  2. 自动进行重试（最多 3 次）
  3. 重试间隔 500ms
  4. 若所有重试均失败，记录错误并报告

4.3 寄存器地址映射

每个加热片占用 12 个寄存器：

偏移 寄存器 说明
0 电压 实际值 = 寄存器值 / 10 (V)
1 电流 实际值 = 寄存器值 / 10 (A)
2 温度 实际值 = 寄存器值 / 10 (°C)
3 功率 实际值 = 寄存器值 / 10 (W)
4 报警状态 位标志
5 控制寄存器 0:停止 1:启动 2:校准
6 目标功率 实际值 = 寄存器值 / 10 (W)
7 运行状态 0:停止 1:运行
8 最大功率限制 实际值 = 寄存器值 / 10 (W)
9 过压阈值 实际值 = 寄存器值 / 10 (V)
10 过流阈值 实际值 = 寄存器值 / 10 (A)
11 过温阈值 实际值 = 寄存器值 / 10 (°C)

4.4 报警状态位定义

位 报警类型
bit 0 过压报警
bit 1 过流报警
bit 2 过温报警
bit 3 漏水报警
bit 4 通信故障

六、常见问题

6.1 连接失败

可能原因：

  • IP 地址或端口号错误
  • 网络不通
  • 设备未开启
  • 防火墙阻止

解决方案：

  1. 检查 IP 地址和端口配置
  2. 确认网络连接正常
  3. 验证设备 Modbus-TCP 服务已启动
  4. 检查防火墙设置

6.2 数据读取异常

可能原因：

  • 通讯超时
  • 寄存器地址配置错误
  • 设备响应数据格式不正确

解决方案：

  1. 检查网络延迟
  2. 确认寄存器地址配置正确
  3. 查看日志获取详细错误信息
  4. 系统会自动进行重试

6.3 校准失败

可能原因：

  • 加热片未连接
  • 校准超时
  • 设备异常

解决方案：

  1. 确认加热片已连接且正常
  2. 增加校准占空比
  3. 重试校准操作
  4. 检查设备状态

6.4 参数保存失败

可能原因：

  • 设备连接断开
  • Flash 写入失败
  • 参数值超出范围

解决方案：

  1. 确认设备连接正常
  2. 重试保存操作
  3. 检查参数值是否在有效范围内
